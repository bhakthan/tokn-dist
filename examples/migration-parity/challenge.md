# Challenge

1. Explain which order invariant the event oracle checks when grouped by
   `order_id`.
2. Change one event payload without changing the number of cases. Re-record
   only after deciding that the changed corpus is approved.
3. Use a held-out input that was not used to create `fixtures.json`. State
   what the ledger proves and what it does not prove.

Do not run these scripts against real data or an untrusted repository.
