# Claims intake desk (synthetic)

This folder is the working area of an always-on claims intake agent. All
names, numbers and policies are invented for testing.

- `policies/` holds policy wordings. Each clause has an id in brackets.
- `claims/` holds first notices of loss (FNOL) as they arrive.

The agent reads these files and answers adjusters' questions. It does not
decide coverage or payment. A licensed adjuster decides.
