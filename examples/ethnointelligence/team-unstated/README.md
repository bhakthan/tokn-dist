# team-unstated

This folder is intentionally empty of declarations. It has no
`environment.json`, so every facet stays **open** when you run
`tokn environment` here.

Use it for the "nothing stated" side of the comparison in the
[walkthrough](../README.md). Do not add a file here: the point is that TOKN
refuses to supply a regime, a currency or a culture on your behalf.
